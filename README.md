# Web-Development

## 📌 Project Overview

** Project** is a multimedia-based educational project designed for children. It uses **images, audio (voice), and simple HTML** to make learning fun and interactive. The project appears to focus on **alphabets, animals, poems, and visual learning**, making it suitable for early childhood education.

---

## 🎯 Objectives

* Help children learn alphabets with **images and voice support**
* Provide a **visual + audio learning experience**
* Make learning engaging through **pictures, poems, and sounds**

---

## 🧩 Project Structure

```
 Project/
│
├── code/
│   ├── Images (.jpg, .png, .avif)
│   ├── Audio files (.mp3)
│   ├── poem.html
│   └── Alphabet & animal resources
│
├── images/
│   └── Additional visual assets
│
├── voice/
│   └── Voice/audio files for learning
```

---

## ✨ Features

* 📸 Alphabet and animal images (A–Z)
* 🔊 Voice/audio pronunciation support
* 📜 Poem display using HTML
* 🧒 Child-friendly and simple design
* 🌈 Visual learning with multimedia content

---

## 🛠️ Technologies Used

* **HTML** – for displaying poems and content
* **Images (JPG, PNG, AVIF)** – for visual learning
* **MP3 Audio Files** – for voice guidance
* **CSS (inline)** – basic styling in HTML

---

## ▶️ How to Run the Project

1. Download or extract the project folder
2. Open the `Sana Project` directory
3. Go to the `code` folder
4. Double-click on `poem.html`
5. The project will open in your **web browser**

> ✅ No installation or server setup required
